# Input suppression owner

This repository owns a final route-mask filter, per-source contact masks,
button disposition and frame boundaries. It has no layer watcher, profile
registry, producer publication API, settings adapter or direct HID calls.

Keep executable fixtures and assertions in tests/. Read tests/README.md and
resolve/read the selected ZMK/Zephyr dependencies before tests. Run the documented
host and both supported-core native entries after interface/behavior changes.
Use fresh evidence paths; preserve ordered output and classified failures.
Host/native/build results do not establish physical HID/BLE/split acceptance.

Keep changes local. Do not commit, push, publish, update a PR, flash or erase
settings without explicit user instructions. Preserve unrelated changes.
Archive unique assertions externally and map intentional contract retirements
before removing fixtures. Do not create rolling whole-tree backups.
